Abstract

Photorealistic Style Transfer (PST) aims to transfer the color and tonal style of a reference to a content image while strictly preserving its structural integrity. However, existing deep learning-based methods inherently suffer from semantic entanglement caused by pre-trained image encoders, leading to unnatural spatial distortions. Moreover, current pixel-level mapping paradigms often ignore color gamut topology, resulting in color banding, while also lacking the multimodal capability for precise, tone-specific text-driven control.

To address these bottlenecks, we propose StatLUT, an innovative multimodal framework for 3D LUT generation. First, we bypass traditional encoders and introduce a Lab-Extractor to derive spatially-agnostic statistical features, fundamentally decoupling color distributions from structural semantics to ensure artifact-free rendering. Second, we formulate LUT generation as a Transformer-based Seq2Seq translation task, utilizing a Multi-dimensional Residual Mapper (MR-Mapper) to predict topologically smooth 3D LUTs. Finally, to break the unimodal barrier, we propose the H-Diffuser, a lightweight Diffusion Transformer that directly synthesizes statistical features from tone-descriptive text prompts, enabling controllable and robust color grading. Extensive experiments on standard benchmarks demonstrate that StatLUT significantly outperforms state-of-the-art methods in both visual quality and quantitative metrics, pioneering a highly robust and versatile paradigm for multimodal photorealistic style transfer.

Overview of the StatLUT framework. The framework consists of three key components: (1) Lab-Extractor for spatially-agnostic statistical feature extraction, (2) MR-Mapper for Transformer-based 3D LUT prediction, and (3) H-Diffuser for text-driven statistical feature synthesis.

Applications

StatLUT enables versatile photorealistic style transfer with both image reference and text-driven color grading control.

Multimodal-Driven PST

Multimodal-driven photorealistic style transfer. StatLUT supports both image-reference and text-driven modes. Given a content image, users can either provide a style reference image or describe the desired style with natural language text prompts, achieving flexible and controllable color grading.

Cross-Semantic Style Transfer

Cross-semantic photorealistic style transfer. StatLUT effectively transfers style across semantically different scenes while preserving structural integrity. The statistical feature representation decouples color distributions from content semantics, enabling robust style transfer even when content and style images have different semantic layouts.

Semantic Interference

To evaluate the impact of semantic structure on style transfer, we shuffle the style image using patches of different sizes (destroying spatial layout while preserving color statistics) and measure the deviation from the baseline PST result (unshuffled style). Larger deviation indicates stronger sensitivity to semantic layout. StatLUT shows minimal deviation across all shuffle levels, demonstrating effective decoupling of color distribution from structural semantics.

Semantic interference ablation study. Row 1 (baseline): Content, Style, and PST results from different methods using the original unshuffled style. Rows 2–5: PST results when the style image is shuffled with increasing patch granularity (2×2, 3×3, 4×4, 5×5). Numbers below each result indicate the deviation from the baseline PST result. Larger values indicate greater sensitivity to spatial semantic structure. StatLUT maintains consistently low deviation across all shuffle levels, while other methods show significant degradation as semantic layout is destroyed.
